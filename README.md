# Scripts — Coywolf + the operator

Screenwriting projects developed through the Zen of Story framework.

## Structure

Each project lives in its own subfolder:

```
scripts/
  PROJECT-NAME/
    character.md        — P-R-I-E-P-I-O-T-S character breakdown
    outline.md          — 3-act, 8-sequence structure
    beatsheet.md        — 37-beat Zen of the Hero's Journey
    treatment.md        — Prose narrative
    draft-v1.fountain   — First draft (Fountain format)
    draft-v2.fountain   — Revisions
    notes/              — Session notes, ideas, research
```

## Process (in order)

1. Ideation/Concepting — conversation, no document
2. Character Creation → character.md
3. Outlining → outline.md
4. Beat Sheet → beatsheet.md
5. Treatment → treatment.md
6. First Draft → draft-v1.fountain
7. Revisions → draft-v2.fountain, etc.

## Future: Wroom

This repo is the data layer for Wroom — a browser-based writers room app where Operator can dictate or write from anywhere in the world, with Coywolf as co-writer.
